# Expense Tracker

Offline Python expense tracker using SQLite.

Run: python main.py

## Installation

Clone the repository:

```bash
git clone https://github.com/Madarax018/expense-tracker.git
cd expense-tracker
```

## Running the project

Run `python main.py`.

## Automated testing

Run the tests locally:

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs these tests automatically when
changes are pushed or a pull request is opened.
